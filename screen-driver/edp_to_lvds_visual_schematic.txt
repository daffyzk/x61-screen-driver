================================================================================
                            LVDS SIGNAL MAPPING
================================================================================

    PTN3460 Output          Signal Content              Panel Input
    ──────────────          ──────────────              ───────────
    LVSAO_P/N (53/54)  →    R0-R5, G0 (Ch A)       →   RIN0+/- (6/5)
    LVSBO_P/N (52/51)  →    G1-G5, B0, B1 (Ch B)  →   RIN1+/- (9/8)
    LVSCO_P/N (48/49)  →    B2-B5, HS, VS, DE (Ch C) → RIN2+/- (12/11)
    LVSCKO_P/N (46/47) →    Pixel Clock            →   CLKIN+/- (15/14)

    Note: Using "Odd" bus outputs only (single channel mode)
          "Even" bus outputs (pins 31-42) are unused
          Channel D outputs (pins 43/44) unused in 18bpp mode

================================================================================
                                NOTES
================================================================================

1. All capacitors: X5R or X7R ceramic, 0402 or 0603 package
2. All resistors: 0402 or 0603 package, 1% tolerance
3. Ferrite beads: High frequency type, e.g., BLM18AG601
4. Use 4-layer PCB with solid ground plane
5. Match differential pair lengths within 5 mils
6. Keep eDP and LVDS traces short and direct
7. Ensure good thermal connection for center pad
8. AC coupling caps (C13-C18) should be close to PTN3460
